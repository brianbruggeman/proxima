# proxima-mlir

Text-only MLIR interchange for the proxima tensor algebra: Linalg export, and torch and StableHLO import, over sans-IO pipes.

The crate is `no_std` by default and has no dependencies of its own; `alloc` and `std` are additive features.

## Features

`alloc`, `std`, `default`; see `[features]` in `Cargo.toml`.

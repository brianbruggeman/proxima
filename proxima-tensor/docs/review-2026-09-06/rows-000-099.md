# Discipline-row audit: ROW 0 through ROW 99

Audit date: 2026-09-06. Source reviewed: `proxima/proxima-tensor/docs/discipline.md`,
including the full row bodies, tables, addenda, rollback notes, and later
corrections that explicitly supersede an earlier row. No build, test, or timed
benchmark was run for this audit.

## Scope and accounting

There is one occurrence for every ID from 0 through 8, 10 through 82, and 83
through 99. `ROW 9` is absent. The file then contains out-of-order `ROW 263`
and `ROW 264` before `ROW 83`; those occurrences are recorded separately below.
The evidence labels in this audit are `MEASURED` (run output recorded by the
row), `DERIVED` (arithmetic from recorded values), `ASSUMED` (an explicit
assumption or unmeasured projection), and `RETRACTED` (later text withdraws or
invalidates the earlier claim). “Current relevance” is evidence scope, not a
verdict about the implementation.

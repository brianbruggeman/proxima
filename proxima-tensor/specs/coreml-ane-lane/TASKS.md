Each slice: one commit, one requirement, one validation command, the AC it repeats. Update the checkbox and the note IN THE SAME COMMIT as the slice. Slice N discharges the AC named in its row and the requirement that AC names; a slice whose command is a subset of its AC says so and the AC reaches its full count when the last slice of that AC lands. Every dependency is added by `cargo add` from the command line; the workspace member list and the feature table are manual edits.

`OUT` is `/Users/brianbruggeman/repos/slot-0/.long_ctx_backups/ane/out`, created once by `mkdir -p "$OUT/incumbent"`; `PKG` is `$HOME/.cache/proxima/coreml-lane`; `LOCK`, `E2B` and `GRANITE` are bound in SPEC.md under acceptance criteria.
